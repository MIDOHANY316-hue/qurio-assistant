# Qurio Assistant
واجهة عربية تجريبية متجاوبة لمساعد تدريبي في البرمجة.

## النشر على Vercel
يمكن استيراد مستودع GitHub الذي يحتوي هذه الملفات في Vercel، دون إعدادات بناء خاصة؛ مجلد الجذر هو المشروع.

## ملاحظات مهمة
- تسجيل الدخول في هذه النسخة تجريبي داخل المتصفح فقط، وليس حسابات آمنة.
- إدخال `admin` ككود طالب يعرض لوحة الأدمن الشكلية فقط.
- إرسال السؤال يعرض رسالة استلام تجريبية؛ لم يتم ربط نموذج ذكاء اصطناعي أو API.
- معاينة الصور محلية داخل المتصفح ولا يتم رفعها إلى خادم.
- لا تدخل بيانات دخول منصة Qureo الحقيقية.
